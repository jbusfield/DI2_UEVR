Get <A HREF="https://www.nexusmods.com/deadisland2/mods/19?tab=files">OptiScaler</A>. Pick the one that says "OptiScaler for Dead Island 2". Extract the contents of the zip into your game folder. The game folder should then look like this

Run the game and go to the game Main Menu screen without starting UEVR. Then go into the game Display settings and set the DLSS setting under Advanced

Go back to the game Main Menu (saving the changes you made when asked) and press INS on the keyboard. Make sure all the checkboxes in this section are unchecked, then press the save button at the bottom and close the overlay

Get the Joey build of <A HREF="https://github.com/PureDark/UEVR/releases/tag/UEVR_AFW_v1.0-beta.6">AFW beta 6</A> and then run that version of UEVR with the current profile
