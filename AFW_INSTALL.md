## Running with AFW

### OptiScaler
Get <A HREF="https://www.nexusmods.com/deadisland2/mods/19?tab=files">OptiScaler</A>. Pick the one that says "OptiScaler for Dead Island 2". Extract the contents of the zip into your game folder. The game folder should then look like this

<img width="547" height="398" alt="DI2_AFW_1" src="https://github.com/user-attachments/assets/298ccd36-14af-4f83-be1e-879b82c4ffe6" />

### Game Settings
Run the game and go to the game Main Menu screen without starting UEVR. Then go into the game Display settings and set the AMD FidelityFX setting under Advanced

<img width="518" height="536" alt="DI2_AFW_2" src="https://github.com/user-attachments/assets/901b85e5-000a-43b1-bca5-d3c33a676c10" />

### OptiScaler Settings
Go back to the game Main Menu (saving the changes you made when asked) and press INS on the keyboard. Make sure all the checkboxes in this section are unchecked, then press the save button at the bottom and close the overlay

<img width="420" height="509" alt="DI2_AFW_3" src="https://github.com/user-attachments/assets/b9a77eeb-fd89-415e-9c77-2c7a3ce0a36a" />

### UEVR
Get the Joey build of <A HREF="https://github.com/PureDark/UEVR/releases/tag/UEVR_AFW_v1.0-beta.6">AFW beta 6</A> and then run use that version of UEVR to install the <A HREF="https://github.com/jbusfield/DI2_UEVR/releases/latest">current profile</A>. Replace config.txt in the profile with the one <A HREF="https://github.com/jbusfield/DI2_UEVR/blob/main/AFWConfig/config.txt">found here</A>

<img width="558" height="200" alt="DI2_AFW_4" src="https://github.com/user-attachments/assets/3635325f-3368-423f-beac-e0998ceeebd8" />

Inject UEVR and enjoy AFW!
