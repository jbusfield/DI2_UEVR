# DI2_UEVR
A mod for UEVR when playing Dead Island 2

## Features include:

- Full 1st person 6DOF Motion controls
- Optional IK arms
- Articulated and animated hands
- Physical gestures for melee combat
- Weighted weapons - (e.g.  Sledgehammers are heavier than swords and therefore require more swing force to connect)
- Option to attach the UI to head movement
- Support for physical gunstocks

## Notes:
- Weapon Wheel - Hold B button (X on the left physical controller) while the wheel is open and then the right stick will cycle through weapons for the currently selected slot in the same way Dpad does
- L3+R3 - UEVR by default use L3+R3 to open it's UI. But in this game, L3+R3 enables Rage mode in your avatar. For this reason, you must long hold L3+R3 (several seconds) in order to open the UEVR UI. Note that this will prevent the UEVR overlay from appearing when you go into rage mode, but if you show the UEVR overlay and then dismiss it with L3+R3, rage mode if available, will be triggered by the dismissal. There are several ways to avoid this.
<BR>  1 - Only dismiss UEVR overlay by pressing the INS keyboard button
<BR>  2 - Go to the game menu before opening the UEVR overlay. With the game menu showing, rage cant be triggered
<BR>  3 - Set the Interaction Controls dropdown to Full Immersion and then rage cant be activated by L3+R3, it can only be activated by Left Trigger near the eyes.
